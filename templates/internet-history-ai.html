Introduction

The internet is a large system of connected computer networks around the world and owned by different people, which allows them to share data to each others.

It all began in October 1969 as ARPANET which is a project funded by the US department of Defense. It was the first network that worked at the time by breaking the data into small chunks and sending it.

Afterwards, we see multiple milestones achieved from this very first step to the internet world, such as sending the first email in 1971, ethernet invention in 1973, and so on.

We will take a look at three key technologies which are TCP/IP in 1983, DNS in 1983–1984, and the World Wide Web (www) / HTTP and HTML from 1989 till 1991.

1. TCP/IP

Milestone: The “Flag Day” protocol transition

Year: 1983

Event

On January 1, 1983, every host on ARPANET was required to switch from the older Network Control Protocol (NCP) to TCP/IP, developed by Vinton Cerf and Robert Kahn. TCP/IP split communication into a reliable transmission layer and a simpler routing layer, allowing data to move between dissimilar, independently operated networks.

Why it mattered

This gave the internet its defining architecture — a “network of networks” that lets any TCP/IP-compliant system exchange data with any other, regardless of the underlying hardware. It remains the core protocol suite of the internet today.

2. DNS (Domain Name System)

Milestone: Introduction of a distributed naming architecture

Year: 1983–1984

Event

Paul Mockapetris, at USC’s Information Sciences Institute, published RFC 882 and RFC 883 in 1983, proposing a hierarchical, distributed system to replace the single manually-maintained hosts.txt file used to map computer names to numeric addresses. He built the first working name server, “Jeeves,” in 1983–84; the system was formally standardized in RFCs 1034 and 1035 in 1987.

Why it mattered

DNS let people use memorable names instead of numeric IP addresses and distributed the job of managing those names across many servers instead of one central authority — a design that scaled with the internet’s growth and remains its core naming infrastructure.

3. World Wide Web (HTTP/HTML/URL)

Milestone: Invention of the web at CERN

Year: 1989–1991

Event

Tim Berners-Lee, a researcher at CERN, proposed a hypertext-based system for linking documents across computers in March 1989. By late 1990, with Robert Cailliau, he had built HTML, URLs, and HTTP, along with the first browser/editor and web server. The first website went live on August 6, 1991, and CERN released the software into the public domain in 1993.

Why it mattered

The web is the application layer that made the internet browsable and usable by non-specialists rather than a tool limited to technical users, and CERN’s royalty-free release was central to its rapid, unrestricted global adoption.
