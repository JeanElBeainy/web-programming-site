Introduction

The World Wide Web, or simply called the Web, is a system of documents that are linked together and can be accessed through the internet. It is not the same thing as the internet; the internet is the network that carries the data of the Web.

It began between 1989 and 1991, when Tim Berners-Lee proposed a way for scientists to link their documents together on different computers without exchanging them manually, and it has been growing and changing ever since.

This page follows the Web itself across six milestones, from 1989 up to today: the invention at CERN, CERN’s decision to give the Web away and the arrival of Mosaic, the W3C and open standards, the scriptable Web, the mobile Web and HTML5, and the Web platform as it stands in 2026.

The network underneath it is covered separately on the History of the Internet page.

1. Birth of the Web at CERN

Milestone: Invention of the Web, and the first website

Year: 1989–1991

Event

Tim Berners-Lee, a researcher at CERN, wrote “Information Management: A Proposal” in March 1989, describing an internet-based hypertext system for linking documents on different computers. With Robert Cailliau he refined it into a formal proposal in November 1990 and, by the end of that year, had built the three building blocks of the Web — HTML for formatting documents, HTTP for transferring them, and URLs for identifying them — together with the first browser/editor and web server, which ran on a NeXT computer. The first website went live at info.cern.ch on August 6, 1991.

Why it mattered

The Web is the application layer that made the internet browsable and usable by non-specialists, turning a network for technical users into a system of interlinked, navigable documents that could be published by anyone.

2. A Free, Open Web: the Public-Domain Release and Mosaic

Milestone: Public-domain release and the NCSA Mosaic browser

Year: 1993

Event

On April 30, 1993, CERN put the World Wide Web software in the public domain, so that anyone could run a server or write a browser without paying royalties or asking permission. That same year, Marc Andreessen and Eric Bina at the University of Illinois’s National Center for Supercomputing Applications (NCSA) released Mosaic, a browser for Windows, Macintosh and Unix that displayed images inline with the text and was distributed free of charge.

Why it mattered

CERN’s royalty-free release is credited with the Web’s rapid, unrestricted adoption, and Mosaic’s ease of use is widely credited with turning the Web from an academic tool into something ordinary people could use — it set the visual and navigational template for every browser that followed.

3. The W3C and the Standardization of the Web

Milestone: HTML 2.0, CSS1 and HTML 4 make the Web interoperable

Year: 1994–1998

Event

In October 1994, Tim Berners-Lee founded the World Wide Web Consortium (W3C) at MIT, in collaboration with CERN, DARPA and the European Commission, to steer the Web’s development so that no single company could control it. The W3C then published specifications that any browser could implement: HTML 2.0 in 1995, CSS1 for styling in December 1996, and HTML 4 in 1997.

Why it mattered

Shared, royalty-free standards are what let pages written once display correctly in every browser, and they prevented the Web from splitting into incompatible versions owned by competing vendors. That is still how the Web is developed today.

4. The Dynamic, Scriptable Web

Milestone: ECMAScript, XML and HTTP/1.1 make pages interactive

Year: 1999–2005

Event

JavaScript, written at Netscape in 1995 by Brendan Eich, was standardized as ECMAScript in ECMA-262 in 1997, and XML 1.0 became a W3C Recommendation in February 1998. HTTP/1.1 was published as RFC 2616 in June 1999. Together with the XMLHttpRequest object, these technologies let a page request new data and update part of itself without reloading — the technique later called Ajax.

Why it mattered

Pages stopped being static documents and became applications that run inside the browser. This is the foundation of every modern web application, from maps and mail clients to the sites and frameworks used today.

5. The Mobile Web and HTML5

Milestone: Responsive browsing and the HTML5 Recommendation

Year: 2007–2014

Event

As smartphones and tablets spread through the 2000s and 2010s, browsing moved from desktop computers to small touch screens, and sites switched to responsive layouts that adapt to any screen size. In parallel, the W3C worked on a new version of the language: HTML5 became a W3C Recommendation on October 28, 2014, adding native audio and video playback without plugins, the canvas element for drawing and animation, native support for SVG and MathML, and better accessibility features.

Why it mattered

HTML5 brought to the browser what previously required separate plug-ins, and the mobile Web made the Web the first place most people now go online. Together they turned the Web from a collection of pages into the platform that applications are delivered on.

6. Today’s Web

Milestone: HTTP/2 and HTTP/3, and WebAssembly

Year: 2014–2026

Event

The way pages travel is being rebuilt for today’s traffic: HTTP/2 (RFC 7540, May 2015) and HTTP/3 (RFC 9114, June 2022) replaced much of HTTP/1.1’s behaviour and moved delivery onto faster, encrypted transports. In December 2019, WebAssembly became a W3C Recommendation, allowing code compiled from other languages to run in the browser at near-native speed.

Why it mattered

These changes made the Web fast and capable enough to host software that used to require an installed application, and the standards process behind them keeps the Web open to any browser and any user rather than tied to one vendor.
